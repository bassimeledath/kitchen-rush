# Working name candidates

| Name | Why it fits |
|---|---|
| **KitchenBench** | Clearest choice: preserves the visual identity and says what the project is. |
| **OrderUp** | Memorable and centered on completed work; use the subtitle “An action-efficiency benchmark.” |
| **KitchenCraft** | Emphasizes applying skills to unfamiliar kitchens, with less emphasis on speed. |
| **ToolKitchen** | Makes the tool-use setting explicit, though v2 specifically tests action selection. |
| **Action Budget** | States the research question directly and can extend beyond kitchens. |

Recommendation: **KitchenBench** for clarity, or **OrderUp** for a more distinctive public
identity. Keep Kitchen Rush as the working name until a name is selected. The shared tagline
works with either: **Useful work. Limited budgets. Unfamiliar kitchens.**
